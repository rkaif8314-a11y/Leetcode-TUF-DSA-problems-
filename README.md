## Naming Convention

Each problem follows:

```text
SECTION/XX-problem-name-leetcode-XXXX/
```

- `XX` = learning order inside that section.
- `problem-name` = clean, valid problem name.
- `leetcode-XXXX` = original LeetCode number, only when applicable.

This means you can study from top to bottom while still being able to identify the original LeetCode problem.

## Study Rule

For every new problem:

1. Understand the concept through the question.
2. Try the solution yourself.
3. Debug and understand why it works.
4. Add clean comments to the C++ solution.
5. Add a README with the approach, complexity, key concepts, and common mistakes.
6. Place the problem in the correct learning position.
7. Preserve the original LeetCode number in the folder name when applicable.
